BrandboxItems
Current version: v3.0.0
Created by: Arjan van den Broek

=========================

Brandbox slider to slide images or videos with 2 lines overlay. Also optional link to page, newsItem or other.
If there's no image provided the video won't show because of fallbacks.

=========================

There is a snippet in the site snippets folder to use for showing (by default used in site home view)

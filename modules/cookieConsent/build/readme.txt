CookieConsent
Current version: 3.1.2
Created by: Rico Schwab

=========================

Informs visitors about the usage of cookies on the website and gives them the ability to allow or deny tracking cookies.

========================

Installation in other templates:
There is 1 snippet included in this module.
init.inc.php needs to be included in the layout.inc.php file after the HTML title tag
See /modules/core/site/default/views/layout.inc.php for example

=========================
